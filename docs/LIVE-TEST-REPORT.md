断线后的第一次重连遇到 `ECONNRESET`。检查 VPS relay 仍为 `active/running`，没有服务退出记录；没有据此重发模型任务。保留本地 journal，随后显式恢复原 session 成功，worker epoch 推进到 4，已有操作数量不变。该故障如实保留在 JSON 中；未确定它发生在 SSH 网络链路的哪一端。

自动批准仅用于测试自己创建的临时项目，命令限制为已知测试脚本。普通 CLI 仍逐次请求本地批准，非 TTY 输入默认拒绝修改和命令；本次测试不授予用户其他项目任何自动执行权限。

## 资源观察

P0 两轮共 13038 ms，`getrusage(RUSAGE_CHILDREN).ru_maxrss` 为 278504 KiB。这是子进程峰值 RSS 指标，不是整个服务的内存总和。

完整测试期间观察到服务 cgroup `MemoryPeak=473432064` 字节（约 451.5 MiB），结束后 `MemoryCurrent=273813504` 字节；cgroup 指标包含文件缓存等内存，不能与单进程 RSS 混用。该机器完成了上述短任务，但这不建立长上下文、压缩、多并发或长期运行的容量结论。
