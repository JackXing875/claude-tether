# Claude Tether v0.2.0-beta.1

Claude Tether is a lightweight launcher that keeps the official Claude Code CLI on your machine while sending its HTTPS connections through your VPS over SSH.

This beta introduces a one-time setup and a single daily command:

```bash
npm install --global https://github.com/JackXing875/claude-tether/releases/download/v0.2.0-beta.1/claude-tether-0.2.0-beta.1.tgz
claude-tether setup my-vps
cd your-project
claude-tether
```

Prerequisites: Node.js 24.14+ in the 24.x line, local official Claude Code, and verified key/ssh-agent access to an SSH server that permits TCP forwarding. `my-vps` may be an SSH alias or `user@host`. The VPS requires no Claude installation, project checkout, database or custom service.

## Included

- Prebuilt npm package with zero runtime dependencies and corresponding source.
- SSH keepalives and automatic reconnect with backoff; the local Claude process stays running.
- A stable loopback proxy, streaming backpressure, cancellation and no idle deadline on established streams.
- Saved defaults, one-time overrides, `doctor`, and passthrough of official CLI arguments after `--`.
- Transport and packaging tests, English documentation, and the repository's GPL-3.0-only license.

## Beta scope

Linux is validated using local OpenSSH and TLS integration tests. Live Claude account requests, a user's VPS, long-running network conditions, macOS and Windows native are not yet validated. Interrupted streams cannot be made lossless by reconnecting SSH; Tether never automatically replays model requests or tools. Ordinary HTTP and UDP are not supported.

The `SHA256SUMS` asset covers the prebuilt tarball. To verify a downloaded copy, place both files in the same directory and run `sha256sum --check SHA256SUMS` before installing the local `.tgz`.

This release replaces the earlier remote-agent/tool-bridge prototype. There is no database or credential migration: configure a local SSH destination and use the official local Claude login.
