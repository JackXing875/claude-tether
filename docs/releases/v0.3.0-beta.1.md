# Claude Tether v0.3.0-beta.1

This prerelease closes a routing gap in 0.2: Claude project settings could override proxy variables and send requests directly. The new default Linux/WSL mode runs official Claude and its child tools in a loopback-only network namespace. HTTP(S) uses SSH to your VPS; other external IP traffic is blocked, including when `NO_PROXY=*` is set.

```bash
sudo apt-get install bubblewrap
npm install --global https://github.com/JackXing875/claude-tether/releases/download/v0.3.0-beta.1/claude-tether-0.3.0-beta.1.tgz
claude-tether setup my-vps
claude-tether
```

Requires Linux/WSL, bubblewrap 0.9+ with usable user namespaces, Node 24.14+ in the 24.x line, official local Claude Code and trusted key/agent SSH access. Existing 0.2 preferences now select isolation unless compatibility mode is explicitly saved. Unsupported isolation fails without silently falling back; `--network proxy` explicitly retains the older behavior.

Also included:

- Ordinary HTTP forwarding, bounded streaming bridges, and process-tree cleanup after normal termination or launcher SIGKILL in isolated mode.
- An experimental `--ccproxy-port` SSH gateway connector, disabled by default. Synthetic tests against pinned upstream passed; real Pro use through ccproxy remains unvalidated. Upstream TLS/key-log/capture/listener concerns are documented, and no identity spoofing is enabled.
- Build cleanup to prevent stale outputs from earlier architectures, complete packaged documentation, and version-triggered GitHub prereleases.
- 29 automated tests, packed installation verification, zero production dependency audit findings, and real official Pro validation of Sonnet tools/MCP/hooks, Opus session resume and native `/model`.

Isolation blocks proxy-unaware tools, UDP and host loopback access; it does not provide a transparent system-wide VPN. Windows interop and host SSH-agent access from Claude are disabled. Filesystem/Unix-socket access remains available, so this is not a hostile-code sandbox. Interrupted model streams are not replayed or resumed by Tether. No account-ban guarantee is made.

See [network compatibility](https://github.com/JackXing875/claude-tether/blob/v0.3.0-beta.1/docs/NETWORK.md), [ccproxy status](https://github.com/JackXing875/claude-tether/blob/v0.3.0-beta.1/docs/CCPROXY.md) and [live evidence](https://github.com/JackXing875/claude-tether/blob/v0.3.0-beta.1/docs/ISOLATED-LIVE-REPORT.md). Download the tarball and `SHA256SUMS` together and run `sha256sum --check SHA256SUMS` before local installation. This release is distributed on GitHub, not published to the npm registry.
