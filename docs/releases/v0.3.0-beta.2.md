# Tether v0.3.0-beta.2

The primary command is now `tether`. The existing `claude-tether` command remains available as a compatibility alias.

```bash
npm install --global https://github.com/JackXing875/claude-tether/releases/download/v0.3.0-beta.2/claude-tether-0.3.0-beta.2.tgz
tether setup my-vps
tether
```

An existing installation can run `tether` immediately after upgrading; setup is only needed for first use or a changed destination. Preferences remain in `~/.config/claude-tether/config.json` (or under `$XDG_CONFIG_HOME`), and the package and repository remain named `claude-tether`.

Pass official Claude arguments after `--`, for example `tether -- --continue`. The SSH transport, authentication behavior and default isolated networking are unchanged. VS Code extension integration is not part of this release.

Validation includes the transport suite and installation of the actual tarball, checking both executable names. Download `SHA256SUMS` with the tarball and verify it with `sha256sum --check SHA256SUMS` before installation.
